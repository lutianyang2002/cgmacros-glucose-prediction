# CGMacros Glucose Prediction and Factor Discovery

This repository implements CGMacros glucose forecasting, baseline reproduction, lifestyle-factor feature construction and ablation, held-out evaluation, and optional supplementary studies. Detailed methodology, results, interpretation, and limitations are in the [RA Brief Project Final Report](RA%20Brief%20Project%20Final%20Report.pdf).

## Repository structure

```text
data/
  README.md                       External-data setup guide
notebooks/                        Pipeline notebooks, 01 through 07
artifacts/                        Selected reviewer-facing outputs
src/                              Project utilities
requirements.txt                  Main Python environment
requirements-ppgr.txt             Optional PPGR environment
pyproject.toml                    Project metadata
RA Brief Project Final Report.pdf  Detailed research report
```

Raw CGMacros data are not committed. `artifacts/` contains selected reviewer-facing outputs, not a complete execution cache.

## Prediction task

The primary task forecasts Libre glucose (mg/dL) 30 minutes ahead from a closed 120-minute history, with origins every five minutes. Results are reported under Protocol A (within-subject future prediction) and Protocol B (unseen-subject generalization). Validation selects configurations; held-out test data evaluate fixed choices. The machine-readable task and split specifications are [`task_protocol.json`](artifacts/03_eda_task_samples/task_protocol.json) and [`split_rules.json`](artifacts/03_eda_task_samples/split_rules.json).

## Data setup

Download [CGMacros v1.0.0](https://physionet.org/content/cgmacros/1.0.0/) separately. The default dataset root is:

```text
data/raw/cgmacros-v1.0.0/
```

Alternatively, set `CGMACROS_DATA_DIR` to the dataset root, which must contain `CGMacros/` and the `DataDictionary*` files. [data/README.md](data/README.md) is the authoritative guide to the required layout, checksum checks, and external-data configuration.

## Environment setup

From the repository root, create and activate a virtual environment, then install the project dependencies.

**PowerShell**

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

**POSIX**

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

The main pipeline targets Python 3.11; `requirements.txt` installs the local package and the Parquet dependencies.

## Reproducing the main pipeline

Run Jupyter or VS Code from the repository root. For a full reproduction, configure the external data and execute:

```text
01 → 02 → 03 → 04 → 05 → 06
```

Downstream notebooks consume artifacts generated by earlier stages. Start at Notebook 01 rather than assuming a later notebook can run from the selected committed artifacts. Notebook 07 is optional and separate from the primary pipeline.

## Notebook guide

| Notebook | Role |
| --- | --- |

## Models and factor groups

The main model families are persistence, a linear-trend reference, GlucoBench-style linear regression, Sparacino AR(1)-WLS, Ridge, and shallow gradient boosting. Baseline definitions and selected configurations are in [`baseline_registry.json`](artifacts/04_baseline_models/baseline_registry.json).

| Group | Features |
| --- | --- |
| **G** | Glucose history |
| **A** | Activity |
| **D** | Diet |
| **B** | Baseline/static participant variables |

Feature-group definitions and locked experiments are recorded in [`feature_group_registry.csv`](artifacts/05_factor_ablation/feature_group_registry.csv) and [`locked_experiments.json`](artifacts/05_factor_ablation/locked_experiments.json).

## Outputs and artifacts

The committed `artifacts/` directory is a selected public subset. Large intermediate Parquet tables, prediction caches, and serialized models are regenerated locally and may not be committed; full reproduction should therefore begin upstream.

Key reviewer-facing outputs include:

- [`baseline_validation_metrics.csv`](artifacts/04_baseline_models/baseline_validation_metrics.csv)
- [`validation_ablation_results.csv`](artifacts/05_factor_ablation/validation_ablation_results.csv)
- [`metrics_summary.csv`](artifacts/06_evaluation_report/metrics_summary.csv)
- [`paired_gain_intervals.csv`](artifacts/06_evaluation_report/paired_gain_intervals.csv)
- Figures in [`artifacts/06_evaluation_report/`](artifacts/06_evaluation_report/)

MAE and RMSE are reported at the participant level and as pooled-window summaries. Model selection uses validation data; final metrics and paired comparisons are computed on held-out test data.

## Optional Notebook 07 setup

Notebook 07 contains supplementary studies. Its PPGR reconstruction uses a separate Python 3.9 environment:

```bash
python3.9 -m venv .venv-ppgr
.venv-ppgr/bin/python -m pip install -r requirements-ppgr.txt
export CGMACROS_PPGR_PYTHON="$PWD/.venv-ppgr/bin/python"
```

On Windows, use `.venv-ppgr\Scripts\python.exe` and set `CGMACROS_PPGR_PYTHON` before starting the notebook kernel. The PPGR work is a partial reconstruction, not an exact reproduction.
